# 使用指南

[← 返回 README](../README.md)

## 连接步骤

连接页顶部可以在两种模式间切换，选一次就会记住。

### 相机热点（AP 模式）

1. **相机**：`MENU → 网络菜单 → 连接至智能设备 → Wi-Fi 连接 → 建立连接`（其它 Z 机型在「设定菜单」，D 系列在「设定菜单 → Wi-Fi」）
2. 记下相机屏幕上的 `NIKON_...` 网络名和 8 位密码
3. **手机**：系统 Wi-Fi 里连上该网络（提示「无法访问互联网」时选**保持连接**），或回到 App 点「连接相机」输入 SSID/密码由 App 代连
4. **App**：点「连接相机」，看到型号与电量即成功；随后在「浏览」里选文件下载

### 同一 Wi-Fi（STA 模式）

1. **相机**：`网络菜单 → 连接至智能设备 → Wi-Fi 连接（STA 模式）→ 建立配置`
2. 给配置起名 → 选择家里的路由器 SSID → 输入 Wi-Fi 密码 → IP 选「自动获取」
3. **手机**：连同一个路由器 Wi-Fi（不用连相机热点，手机仍可上网）
4. **App**：模式切到「同一 Wi-Fi」→ 点「扫描并连接」；找不到就用「手动 IP」填相机在局域网里的地址

> 同一时间只能有一个客户端连相机：请先完全退出 SnapBridge。

## 机型支持

| 模式 | 原理 | 支持的机型 |
|---|---|---|
| **AP**（相机热点） | 相机自己开热点，手机连上去，不依赖路由器 | 带 Wi-Fi 的 Z 系列（Z50 / Z50II / Z6 II / Z6 III / Z7 / Z7 II / Z8 / Z9 / Zf 等）以及 D 系列 Wi-Fi 机型 |
| **STA**（同一 Wi-Fi） | 相机加入现有路由器或手机热点，手机在同一网络里通过局域网连它 | 菜单里出现「Wi-Fi 连接（STA 模式）」的机型，如 Z9（C 固件 5.00 起）、Z8、Z50II 等较新机型 |

> 判断方法：相机菜单里能选到「Wi-Fi 连接（STA 模式）」就支持 STA；只有「Wi-Fi 连接」一项时用 AP 模式即可。两种模式功能没有差别，按相机菜单里能选到的那一项使用即可。

## 遥控拍摄

1. 连接成功后，轻触连接页的圆环（整圈都可点）进入遥控拍摄
2. 画面中央是实时取景；左上角是挡位，右上角是延迟拍摄
3. 底部显示光圈 / ISO / 快门 / 曝光补偿 / 焦段；**点这些参数**会弹出刻度尺，拖动选择，点右上角「完成」写入相机
4. 右上角三个图标依次是**白平衡**、**驱动模式**、**延迟拍摄**，点开同样用刻度尺选择
5. 对焦：点左下 `AF` 按钮单次对焦；也可以直接点取景画面任意位置，先移动对焦点再对焦
6. 灰色的是当前改不了的参数：快门、焦段本身只读；AUTO / P 等自动挡下光圈、ISO 由相机接管
7. 取景辅助：右上角图标可开关网格线与峰值对焦；左上角「标准 / 流畅 / 高画质」点一下切换取景画质
8. 间隔拍摄：点右上角定时图标，选间隔与张数后开始；页面会显示「间隔拍摄 n/m」，再次点该图标可停止
9. 按底部快门拍照；若设了延迟，会先显示倒计时，结束才释放

> 取景画面依赖机型支持，可在页面右上角「机型支持」查看尼康官方列表；取不到画面时仍可正常拍照与下载。

## 遥拍页工具

标题栏齿轮（「机型支持」右侧）打开「工具」，里面是：取景画质、间隔拍摄、网格线、峰值对焦、白平衡、驱动模式、延迟拍摄。

- **默认全部关闭**，打开哪一项，画面上才会出现对应图标
- 开关**只控制显示/隐藏**，不会改动已经设置好的值
- 改动过默认值的图标会变成黄色，例如白平衡不再是自动、驱动不再是单张、延迟不是 0
- 取景画质默认「流畅」，链路慢掉帧时会自动再降一档

## 遥控拍摄

1. 连接成功后，轻触连接页圆环进入遥控拍摄
2. 画面左上角是挡位，底部是光圈 / ISO / 快门 / 曝光补偿 / 焦段
3. 对焦：点右侧 `AF` 圆钮单次对焦；或直接点画面任意位置，出现黄色焦点框并合焦
4. 拍参数：点光圈、ISO、挡位、曝光补偿，拖动刻度，点右上角「完成」写入
5. 快门速度只读；焦段是光学变焦只读；**M 挡下曝光补偿只影响测光**，不改变曝光，切到 A / S / P 才生效
6. 延迟拍摄、间隔拍摄：点对应图标设置，倒计时或间隔到了才释放快门
7. 按底部快门拍照，拍完自动取回新照片

> 取景画面依赖机型支持，可在「机型支持」查看尼康官方列表；取不到画面时仍可正常拍照与下载。

**视频/图片怎么打开** — 下载完成后，格子右下角会出现小图标：视频是播放、图片是眼睛，点击用系统播放器或相册打开。

## 常见问题

**连不上 / InitFail** — 相机被其它设备占用，关掉 SnapBridge 后重开相机 Wi-Fi。

**相机不在 192.168.1.x 网段** — 「手动 SSID」里把相机 IP 填上（例如 `192.168.0.1`），App 会直接连这个地址。

**STA 模式扫不到相机** — 多半是路由器开了「AP 隔离 / 客户端隔离」；确认相机和手机在同一个 SSID、同一网段，并临时关掉 VPN / 代理后重试，或者直接用「手动 IP」。

**传输中自动断开** — 关闭手机「WLAN+ / 智能网络切换」，它会把没有互联网的相机网络切走。

**相机一会儿就断** — 设定菜单里把「自动关机时间」调长；半按快门可唤醒。

**RAW 没有缩略图** — 部分机型不对 NEF 返回缩略图，格子里会显示 `RAW` 占位，不影响完整下载。

**下载一半失败** — 直接重试同一个文件，会从 `.part` 的断点继续。

**手机里删了照片，App 还显示「已下载」** — 「已下载」是 App 自己的记录（按相机文件名与大小），不会跟着相册删除而变化。想重新取回时，直接在浏览页选中该文件再下载一次即可；也可以在「设置 → 存储 → 清除下载记录」后刷新列表。

**遥控页按了快门相机没反应** — 先确认相机在 **M / A / P / S** 挡（AUTO 或其它场景模式下部分机型拒绝远程释放）。长曝光时相机会先做降噪、期间不响应指令，App 会等待并提示「已触发拍摄，长曝光/降噪可能要等几秒」。

**视频怎么播放** — 列表里视频格子中间有播放按钮：已下载的直接用系统播放器打开；没下载的会先加入传输队列，传完再点一次即可。

**下载会随着切页中断吗** — 不会。下载进入后台队列，按顺序一个接一个传，浏览页顶部会显示「待传输 N」。

**参数是灰色的点不动** — 说明该参数当前不可远程修改：快门与焦段只读；AUTO / P 等自动挡下光圈、ISO 由相机接管，切到 M / A / S 后再试。

**遥控页没有取景画面** — 该机型不在尼康官方取景支持列表里，或相机正忙。点右上角「机型支持」查看列表；拍照、下载不受影响。

**连不上、想反馈** — 设置页 →「复制诊断信息」，把复制到的内容贴到 [Issues](https://github.com/AchooLuv/NikonLink/issues)，里面已包含相机型号、固件与最近的协议日志。
